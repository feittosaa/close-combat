# Entradas

Adaptar controles remapeáveis para comandos abstratos e direções relativas ao oponente. Tratar bordas, auto-repeat, teclas mantidas, perda de foco, pausa e reset de forma previsível. Reconhecimento de comandos e histórico de inspeção têm responsabilidades distintas.

Somente dados autorizados do personagem definem seus comandos. Rótulos e notações da interface não criam golpes ou receitas. Conteúdo específico e decisões pendentes ficam na pipeline.

Controles usam o mapeamento padrão do navegador (posições, não símbolos impressos), para servir a qualquer fabricante. O primeiro controle conectado joga como P1 e o segundo como P2; teclado e controle do mesmo jogador se somam. Nos menus, só a tela mais recente recebe o controle, para que diálogos sobrepostos não acionem a tela de baixo.
