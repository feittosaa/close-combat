# Shoto — representação provisória

Shoto ainda não possui sprites, retrato ou animações finais. A renderização usa geometria neutra de `CombatantView`; não adicionar assets do elenco retirado.

Quando a identidade visual for definida pelo usuário, entregar nesta pasta fontes editáveis e PNG RGBA em grade uniforme, enquadramento fixo, escala/pés/pivô consistentes, sem HUD ou colisores desenhados. Registrar dimensões e clipes no manifesto próprio, origem, exportação, limites e evidência de revisão no jogo. Seguir [identidade-visual.md](../../../../../identidade-visual.md).
