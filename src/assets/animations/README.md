# Animações exportadas

Guarde aqui arquivos de sequência e metadados exportados pelo fluxo de arte. Os quadros de imagem correspondentes ficam em `../sprites/`.

Use nomes com personagem, ação e versão, por exemplo `fighter-name-idle-v01.json`. Mantenha escala, ordem dos quadros e ponto de pivô documentados junto da exportação. O mapeamento entre animação e modo de combate pertence a `src/rendering/animations/`.
