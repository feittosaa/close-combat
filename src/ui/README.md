Menus, HUD, paletas de botões e ferramentas de treino. A interface comunica o estado da simulação sem ser sua autoridade.

Todo texto visível passa pelos dicionários de `src/i18n/`: o português é a referência, cada idioma cobre todas as chaves com os mesmos marcadores, e nomes de golpes, combos e cenários são traduzidos pelo identificador, mantendo o nome em português nos dados.
